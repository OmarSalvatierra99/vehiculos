# 10-vehiculos

`10-vehiculos` is a Flask project for vehicle control workflows. It follows the portfolio structure with `app.py`, `config.py`, `requirements.txt`, `templates/`, `static/`, `deploy/`, `tests/`, `.env.example`, and `prompts/`.

Use environment variables for secrets and runtime paths. The smoke test isolates SQLite in a temporary directory so it can run without mutating production data.
